
Default discount:

- Enable "Pricelists" and "Discounts" settings option
- Open the default pricelist
- Add fixed price 100 with 20% discount for a selected product
- Create a sale quote
- Ensure the discount is applied

Minimum qty discount:

- For the same product add another price rule
- Set fixed price 80 with 10% discount and minimum qty to 2
- Open the sale quote
- Change qty to 2 and ensure the new price and discount is applied
