Setup:

- Install module sale_timesheet_total_validated
- Install Sale Manegement App
- Open Settings > Timesheets
- Go to Billing section and activate "Invoice > Validated timesheets only"

Check validated timesheets on sale orders:

- Open Sales App
- Choose a quotation with order lines of type "Invoice on Timesheets"
- Click on smart button "Recorded $X hours"
- Chosse on or more timesheets and execute "Validate" action
- Check if sum of recorded hours changes in respect to validated timesheets
