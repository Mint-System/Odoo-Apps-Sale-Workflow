# Odoo Apps: Sale Workflow

Odoo modules extending the `sale` module.

## Usage

Clone this repo into the Odoo addons directory.

```bash
git clone git@github.com:Mint-System/Odoo-Apps-Sale-Workflow.git ./addons/sale_workflow
```
